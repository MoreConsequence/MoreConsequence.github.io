## 描边/边框一致性根治（用户第三次投诉"粗细飘/连边"）

根因：手绘每张 SVG 时给连边/节点边框/箭头标线用了**不统一的 stroke-width**，且无描边令牌系统。实测违规值：CDN 那批节点边框用 1.5、橙色连边用 1.4/1.6/1.8，新文章混 0.8/1/1.2；覆盖网 `arrow-accent` 标线被写成 `markerWidth=9`（比灰色 8 还大）；部分图只定义 1–2 个箭头标线（规范要求 3 个全定义）。

**规范令牌（style-guide.md L113-123 + SKILL.md L293-340）**：
- `0.8` = stroke-thin：坐标轴/基线/内嵌 eyebrow/淡容器
- `1` = stroke-default：节点边框 + 普通连边（中性 #4f5d75）
- `1.2` = stroke-strong：强调/焦点连边（橙色 #eb6c36 的 line/path）
- 箭头标线固定 `markerWidth=8 markerHeight=6 refX=7 refY=3`，polygon `0 0, 8 3, 0 6`；三套 arrow/arrow-accent/arrow-link 必须都定义。1.5 不在规范内。

**修法**：写 `scripts/verify-diagram-strokes.py` 统一审计（stroke 令牌 + 3 标线齐全 + 标线尺寸 + 标签遮罩是否压箭头 + 是否切节点边框）。并用一个归一化脚本把 8 张图全部按令牌重写字宽、补全标线。

**结果**：8 张图（4 CDN-03 + 4 分布式时钟）全部 `ALL PASS`：stroke 仅 0.8/1/1.2；arrow-overlap=0；border-cut=0；self_check 全 OK。

**防复发**：以后每出一张 diagram，先跑 `python3 scripts/verify-diagram-strokes.py <src.html>`，不通过不出图。
