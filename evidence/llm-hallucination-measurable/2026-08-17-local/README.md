# 幻觉可测量性模拟

这份快照只证明仓库里的确定性模拟能够重现三个统计关系：样本量增大时比例估计的散布收缩；把不可判定题当成普通错误时会产生可计算的偏差；按错误类型分栏可以保留修复信号。它不测量任何真实模型，也不证明本文给出的比例可以外推到线上流量。

## 环境与命令

- OS：macOS 26.5.1，Darwin arm64
- Node：v24.19.0
- 随机源：实验内置的 32 位 LCG；题目可判定性与模型错误均由显式 seed 驱动
- 命令：`node experiments/llm-hallucination-measurable/measure.mjs`
- 输出：`raw/measure.txt`

实验 1 固定 `r=0.15`，每个题数重复 100 次；实验 2 固定 `r=0.10`，不可判定题的随机错误率为 0.5；实验 3 固定四类错误率并使用同一个确定性题集。文章表格直接取自 raw 输出，表中 `±` 是 100 次估计的总体标准差，不是 95% 置信区间。

## 边界

题目答案由确定性函数构造，模型错误由伯努利式启发式模拟；没有 tokenizer、上下文、检索、引用解析、人工标注或供应商 API。因此这份证据只能支持统计口径和报告流程的讨论，不能支持“某个模型幻觉率为 X%”或“某个 prompt 让真实模型下降 Ypp”的结论。
