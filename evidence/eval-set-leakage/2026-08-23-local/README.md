评测集泄漏膨胀曲线的模拟原始输出。

## 环境

- darwin/arm64，Node v24.19.0，零第三方依赖
- 工具：`experiments/eval-leakage/leak.mjs`

## 运行命令

```sh
node experiments/eval-leakage/leak.mjs
```

## 方法参数

- seed=20260823（mulberry32），N_EVAL=500，真实能力 P_base=0.5，记忆答对率 P_memorize=0.95；
- 泄漏形态：训练语料包含评测题的**同义改写**（非原文复制）。

## 边界

- 世界是合成的：题目同质、记忆概率固定；真实泄漏还伴随难度分布漂移；
- n-gram 检测器在"改写保留槽位词"的合成设定下表现良好，对真实世界的深度改写/
  翻译型泄漏会显著退化——本实验不为其背书；
- 结论可外推的是方向（准确率随泄漏比例单调虚高、幅度可达数十 pp），不是具体百分点。
