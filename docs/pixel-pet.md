# 可编程的像素伴读宠物

角色由 `lib/pixel-pet.ts` 定义，文章侧栏继续使用 `components/ui/pixel-mascot.tsx`。不需要重新生成 PNG 或 sprite sheet 来增加动作。

## 模型与绘制

视觉保留淡紫头发、奶白圆团子、豆豆眉与半睁眼。身体宽而矮，两侧短发向外卷起；豆豆眉沿用原角色的淡紫小椭圆，眼睛与小嘴使用柔和的梅子色，脸颊保留饱满腮红，手脚收成短短的小豆子。头发与身体使用整块像素色面，仅在刘海保留少量高光。日常动作控制在约 1 个逻辑像素，静默时偶尔探头与点头。继续抽象造型时优先保留圆胖比例、豆豆眉和这组神态特征。

- 画布为 72 × 48 个逻辑像素，页面以 3 倍显示为 216 × 144px。调色板、刘海、短发、书和表情都由代码定义。
- 身体、头、上臂、前臂、腿和头发分别变换，手臂有肩与肘两个关节。走路、跳跃与翻滚同时影响多个部件。
- 动作函数在任意时间计算姿态，活动时画布最多每 50ms 更新一次。React 只在动作、文案或页面状态变化时更新。
- 旋转和形变通过逆变换采样回整数像素格；不直接旋转 Canvas，也不对整个角色应用 CSS 平滑缩放。输出没有半透明的抗锯齿边缘。
- 当前日常动作保持身体与脸部的角度为 0、缩放为 1；移动先吸附到整数像素，再统一绘制各部件。避免对仅几格大小的豆豆眉和五官反复旋转、拉伸，造成丢格与轮廓抖动。待机只保留眨眼；探头、点头在动作中段稍作停留，招手主要动小手。明显的走路、跳舞和翻滚仍保留变换能力。

## 直接增加动作

在 `PET_ACTIONS` 中添加动作函数。`u` 是 0–1 的动作进度，`seconds` 是已播放秒数；返回的 `PetPose` 控制位置、身体形变、各关节角度、头发、表情和道具。函数可以连续计算，或组合已有动作的姿态。

例如，以下定义可加入动作表，生成一次轻轻抬头：

```ts
lookUp: {
  label: "抬头看看",
  duration: 1200,
  still: 600,
  pose: (p, u) => ({
    ...p,
    headY: -Math.sin(u * Math.PI),
    eyes: "happy",
    smile: true,
  }),
},
```

把动作名加入 `PET_CLICK_ACTIONS`，即可通过点击角色播放；也可以从组件调用 `playAction("lookUp")` 绑定专用按钮。`still` 是减少动态效果时展示的代表姿态时刻，单位为毫秒。没有 `loop: true` 的动作播完后回到待机或读书，后来的操作会立即替换当前动作。

## 交互与生命周期

点击角色依次触发贴贴、探头、点头、小幅招手和伸懒腰；下方保留暂停按钮。45 秒没有交互会打盹，点击或移入角色会唤醒。跳跃、跳舞、翻滚与走路仍可通过动作函数调用，日常伴读不自动播放这些明显动作。阅读进度达到 100% 时回应一次，文案只描述滚动到文末。

页面隐藏或宠物离开可视区域时停止逐帧播放；回到视野后继续，不补播隐藏期间的动作。暂停保持当前姿态。`prefers-reduced-motion` 下展示静态动作反馈，保留按钮与气泡；一次性动作仍会回到伴读状态。卸载时撤销动画帧、观察器、监听和定时器。

```sh
npm test -- tests/pixel-pet.test.tsx tests/article.test.tsx

```

动作测试检查完整动作时间轴中的像素整数坐标、调色板、裁切、不同姿态以及播放打断、回归和庆祝时机。真实 Canvas、按钮、暂停、减少动态效果、主题与手机目录需在博客的本地浏览器预览中检查。
